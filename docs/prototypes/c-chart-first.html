What changes from today

  • Chart takes the screen; price and timeframe float over it.
  • Floating dock holds monitoring, the battery action and the links to Alerts and History.
  • OHLC as a tooltip next to the selected candle instead of a line above the chart.

Beyond the spec (decide before Phase 3)

  • Alert lines on the chart: Vico needs a horizontal-line decoration per active alert; targets outside the visible range pin to the edge with an arrow.
  • Long-press to create: direction follows the line (above or below the current price), with nudge buttons and "Type price" as the fallback. A11y: the typed path must stay.
  • Price ladder orders alerts by price, not newest first (spec §4 asks for newest first per list; sort in Kotlin with compareTo).
  • Week stats in History.
