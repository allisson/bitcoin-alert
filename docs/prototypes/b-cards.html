What changes from today

  • Price hero card with a tonal change pill (arrow plus sign, not color only).
  • Monitoring card with a large switch; the battery action lives inside it, next to the control, as the spec asks.
  • OHLC as a labeled grid instead of one text line.
  • Navigation stays in the top bar (icons instead of text buttons).

Beyond the spec (decide before Phase 3)

  • "Next alerts" card on Home with distance to target.
  • Alerts as filter chips (Active, Triggered, Disabled) instead of three stacked lists.
  • Full-screen create with an in-app keypad and "Rises above / Falls below" wording.
  • Slippage (observed minus target) in History.
