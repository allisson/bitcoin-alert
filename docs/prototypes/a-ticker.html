What changes from today

  • Bottom navigation replaces the Alerts and History text buttons in the top bar.
  • Connection status becomes a pill next to the pair (Live, Reconnecting, Stale 14s) instead of a text line.
  • Monospace prices, so digits do not jump while the price updates every second.
  • Monitoring and battery sit in two compact rows above the chart.

Beyond the spec (decide before Phase 3)

  • Distance to target (%) and a progress bar on each active alert.
  • Quick chips (+1%, +2%, round number) in the create sheet.
  • Swipe to delete; the spec only asks for a delete action.
  • History grouped by day; order stays newest first.
  • Icons need contentDescription (open Phase 2 task).
